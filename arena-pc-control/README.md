# 🖥️ Arena PC Control — نظام التحكم الآمن بالحاسوب لـ Arena.ai (نسخة JARVIS)

نظام معياري ومفتوح المصدر يربط **Arena.ai** بجهازك **Windows 10/11** محلياً عبر بروتوكول **MCP (Model Context Protocol)** مع طبقة حماية وصلاحيات صارمة (**Human-in-the-Loop Policy Gate**)، ومستوى جديد من الذكاء المستقل على غرار **JARVIS** — يخطط، ينفذ، يتحقق، يتعافى، ويتذكر — بدون الحاجة إلى صلاحيات المسؤول (Administrator) أو مفاتيح API مدفوعة.

---

## 🤖 ما الجديد في إصدار JARVIS (v0.2.0)

الآن النظام ليس مجرد أداة تنفذ أوامر منفصلة، بل **مساعد ذكي مستقل**:

| القدرة | ماذا يفعل |
|---|---|
| 🧠 **فهم النية (Intent Analysis)** | يحلل ما تقصده فعلياً، وليس فقط ما تقوله حرفياً (بحث ويب، إدارة ملفات، controlling تطبيقات، تطوير، إدارية نظام) |
| 📋 **تخطيط المهام (Task Planning)** | يقسم الهدف الكبير إلى خطوات مرتبة ومترابطة، كل خطوة تحدد الأداة المطلوبة والنتيجة المتوقعة |
| ▶️ **التنفيذ المستقل (Autonomous Execution)** | ينفذ الخطة خطوة بخطوة مع التحقق من كل نتيجة والتعافي من الأخطاء تلقائياً |
| ✅ **التحقق والتحقق المزدوج (Verification)** | يتحقق من أن كل خطوة نجحت فعلياً قبل الانتقال للخطوة التالية |
| 🔄 **التعافي الذاتي (Self-Recovery)** | عند فشل خطوة، يحلل الخطأ، يحاول حلولاً معروفة، ويRetry حتى يصل للنتيجة |
| 🧠 **ذاكرة عميقة مستديمة (Deep Memory)** | يتذكر مشاريعك، قراراتك، أخطائك وحلولها، تفضيلاتك، وسير العمل الناجحة عبر الجلسات |
| 📈 **التعلم الذاتي (Self-Improvement)** | يسجل الأنماط الناجحة والفاشلة ويستخدمها لتحسين التنفيذ المستقبلي |
| 🛑 **إيقاف طارئ (Emergency Stop)** | زر إيقاف شامل يوقف كل العمليات المستقلة فوراً، ولا يُعاد تفعيله إلا بإذنك الصريح |

## 🏗़ Architektur النظام (المعمارية الموحدة)

```text
المستخدم (Arena.ai)
      │
      ▼
[الت Erweiter Extension — Chrome/Edge MV3]
      │  ws://127.0.0.1:18765 (تشفير + فحص Origin)
      ▼
[الجسر الآمن (Bridge Server)]
      │  سياسة ALLOW/CONFIRM/DENY + سجل تدقيق JSONL
      ▼
[JARVIS Core Orchestrator]  ←–– العقل المركزي
      ├── 🧠 IntentAnalyzer        (فهم الهدف)
      ├── 📋 TaskPlanner           (تخطيط الخطوات)
      ├── ⚙️ TaskEngine            (التنفيذ + التحقق + التعافي)
      ├── 🧠 JarvisMemory          (ذاكرة المشاريع والقرارات والأخطاء)
      ├── 📈 SelfImprovement       (التعلم من النجاح والفشل)
      ├── 🛑 EmergencyStop         (الإيقاف الطارئ)
      └── 🔌 MCPRouter              (توجيه الأدوات للخوادم)
            ├── local_pc (مدمج: ملفات، Shell، سطح مكتب Windows، ذاكرة)
            ├── @playwright/mcp (التحكم في المتصفح عبر Accessibility Tree)
            └── أي خادم MCP خارجي تضيفه
```

## ✨ ما يستطيع JARVIS فعله على حاسوبك

1. **المتصفح والويب**: فتح يوتيوب ومواقع أخرى، البحث، قراءة الصفحات، النقر، تعبئة النماذج (عبر Playwright MCP أو الأدوات المدمجة).
2. **الملفات والمجلدات**: إنشاء، قراءة، تعديل، نقل، حذف (بموافقتك)، تنظيم المشاريع.
3. **تطبيقات سطح المكتب**: إدراج النوافذ المفتوحة، تشغيل تطبيقات، التركيز على نافذة، فحص عناصر واجهة المستخدم (UI Automation).
4. **الماوس ولوحة المفاتيح ولقطات الشاشة**: مع مفتاح أمان فوري عند الزاوية العليا اليسرى `(0,0)`.
5. **الطرفية وPowerShell**: تنفيذ أوامر مراقب بها، مع حظر الصلاحيات الإدارية وأوامر تدمير الأقراص.
6. **الذاكرة الدائمة**: تذكر كل مشروع وقرار وخطأ وحل عبر الجلسات.

## 🔐 الأمان (لا تنازل عنه أبدًا)

- ✅ الخادم مرتبط حصرياً بـ `127.0.0.1` — غير متاح للإنترنت أو الشبكة المحلية.
- ✅ فحص `Origin` يمنع أي موقع ويب من الاتصال بالجسر المحلي.
- ✅ رمز إقران مشفر 256-bit (`auth_token.txt`).
- ✅ motore السياسات (PolicyEngine): ALLOW / CONFIRM / DENY — الحذف والتثبيت والكتابة خارج مساحة العمل تحتاج موافقتك الحية.
- ✅ رفض التشغيل بصلاحيات Administrator — يعمل كمستخدم عادي فقط.
- ✅ سجل تدقيق كامل (audit.jsonl) لكل عملية.
- ✅ إيقاف طارئ (Emergency Stop) يوقف كل شيء فوراً.
- ✅禁止 الوصول إلى كوكيز المتصفحات، `.ssh`، ومجلدات النظام الحساسة.

## 🚀 التشغيل على Windows 10/11

1. انسخ مجلد `arena-pc-control` إلى جهازك.
2. شغّل **`start_windows.bat`** (كمستخدم عادي، ليس Admin) — سيظهر رمز **`PAIRING TOKEN`**.
3. ثبّت الإضافة من `arena-pc-control/extension` في Chrome/Edge (Developer mode → Load unpacked).
4. الصق الرمز في أيقونة الإضافة → **Paired & Ready**.
5. افتح `https://arena.ai` → اضغط **Start PC Session** → أعطِ JARVIS هدفاً مثل:
   > "أنشئ مشروعاً جديداً في ~/Projects واحفظ ملاحظات البداية فيه."
