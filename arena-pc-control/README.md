# 🖥️ Arena PC Control — البنية التحتية للتنفيذ لوكيل Arena.ai

نظام محلي آمن يربط **الوكيل الموجود داخل Arena.ai** (الدماغ) بجهازك **Windows 10/11** عبر جسر محلي موحد (Local Bridge) وبروتوكول **MCP**.

---

## 🧠 المبدأ الأساسي: الوكيل الموجود هو الدماغ

**نحن لا نبني ذكاءً اصطناعياً جديداً.** الوكيل الموجود داخل Arena.ai هو بالفعلbrain يمتلك الذكاء والاست reasoning والتخطيط والمحادثة. نظامنا يوفر فقط:

| المكون | المسؤولية |
|---|---|
| **وكيل Arena.ai** (الدماغ) | الفهم، التخطيط، اتخاذ القرارات، طلب الأدوات، تحليل النتائج |
| **الإضافة الكروية (Chrome/Edge MV3)** | الربط بين Arena والجسر المحلي، تسليم استدعاءات الأدوات، عرض موافقات المستخدم |
| **الجسر المحلي (Local Bridge)** | المصادقة، إدارة الجلسات، توجيه الأدوات، حظر العمليات المتضاربة |
| **محرك التحكم بالكمبيوتر (PC Control)** | تنفيذ الأوامر على Windows: ملفات، تطبيقات، متصفح، ماوس/كيبورد، لقطات شاشة، أوامر طرفية |

**لا حاجة لمفاتيح API إضافية.** لا OpenAI، لا Anthropic، لا Gemini، لا Ollama، لا دردشة منفصلة.

---

## 🏗️ التصميم المعماري (Target Architecture)

```
USER
  ↓
EXISTING AI AGENT INSIDE Arena.ai
  (Existing intelligence, reasoning, planning, conversation)
  ↓
UNIVERSAL AGENT CONNECTOR
  (Provider adapters — detects supported Arena agent interfaces)
  ↓
CHROME / EDGE EXTENSION
  (Manifest V3 — non-destructive, Approve/Deny UI, tool routing)
  ↓
LOCAL AUTHENTICATED BRIDGE
  (ws://127.0.0.1:18765 — localhost only, 256-bit token, Origin check)
  ↓
PC CONTROL ENGINE + MCP ROUTER
  (PolicyEngine ALLOW/CONFIRM/DENY, session isolation, resource locking)
  ↓
WINDOWS PC
  (Files, apps, browser, mouse/keyboard, screenshots, CMD/PowerShell)
```

## ✅ ما يوفره النظام (قدرات التحكم بالكمبيوتر)

| الفئة | القدرات |
|---|---|
| **سطح المكتب** | لقطات شاشة، فحص عناصر واجهة المستخدم، التفاعل مع النوافذ، الماوس والكيبورد، التمرير |
| **التطبيقات** | تشغيل التطبيقات، التبديل بينها، التفاعل مع واجهاتها، الإغلاق مع Sicherung |
| **نظام الملفات** | إدراج المجلدات، البحث عن الملفات، القراءة، الإنشاء، التعديل، النقل، الحذف (بموافقة المستخدم) |
| **المتصفح** | التفاعل مع علامات التبويب، التنقل في المواقع، فحص محتوى الصفحات، النقر والكتابة، إدارة التبويبات |
| **التطوير** | إنشاء المشاريع، تعديل ملفات المصدر، تشغيل أوامر التطوير المسموحة، فحص الأخطاء |
| **أدوات Windows** | تنفيذ CMD و PowerShell مراقب، دليل العمل، مخرجات الأوامر، اكتشاف الفشل والTimeout، موافقة للعمليات الحساسة |

## 🔄 حلقة العمل مع وكيل Arena

1. تفتح **Arena.ai** وتختار وكيل ذكاء اصطناعي مدعوماً
2. تعطيه هدفاً على جهازك Windows (مثل: "أنشئ ملفاً في مجلد المشاريع وافتح يوتيوب")
3. الوكيل يقرر ما الأداة المطلوبة ويطلبها عبر الإضافة
4. الجسر المحلي يتحقق من السياسة (ALLOW/CONFIRM/DENY)
5. إذا كانت العملية تتطلب موافقة، تظهر بطاقة **Approve/Deny** في Arena
6. عند الموافقة، يتم التنفيذ على Windows وتُعاد النتيجة إلى الوكيل
7. الوحلل النتيجة ويقرر الخطوة التالية حتى إكمال الهدف

## 🔐 الأمان (لا تنازل)

- ✅ الجسر مربوط فقط بـ `127.0.0.1` — غير معرض للإنترنت أو الشبكة المحلية
- ✅ فحص `Origin` يمنع أي موقع ويب من الاتصال بالجسر المحلي
- ✅ رمز إقران مشفر 256-bit (`auth_token.txt`) مع `hmac.compare_digest`
- ✅ رفض التشغيل بصلاحيات Administrator — يعمل كمستخدم عادي فقط
- ✅ محرك السياسات (PolicyEngine): ALLOW / CONFIRM / DENY — الحذف والتثبيت والكتابة خارج مساحة العمل تحتاج موافقتك الحية
- ✅ سجل تدقيق كامل (audit.jsonl) لكل عملية
- ✅ إيقاف طارئ (Emergency Stop) يوقف كل شيء فوراً
- ✅ حظر الوصول إلى `.ssh`، كوكيز المتصفحات، `.ROBLOSECURity`، ومجلدات النظام الحساسة
- ✅ عزل الجلسات — لا اختلاط بين سياقات الوكلاء المختلفين
- ✅ قفل الموارد — منع العمليات المتضاربة على نفس الحاسوب

## 🚀 التشغيل على Windows 10/11

1. انسخ مجلد `arena-pc-control` إلى جهازك
2. شغّل **`scripts/start.bat`** (كمستخدم عادي، ليس Admin) — سيظهر رمز **`PAIRING TOKEN`**
3. ثبّت الإضافة من `arena-pc-control/extension` في Chrome/Edge (Developer mode → Load unpacked)
4. الصق الرمز في أيقونة الإضافة → **Paired & Ready**
5. افتح `https://arena.ai` وابدأ باستخدام وكيل ذكاء اصطناعي للتحكم بجهازك

## 📋 ما هو مختبر وما هو غير مختبر

| المكون | حالة الاختبار | الملاحظة |
|---|---|---|
| الجسر المحلي (المصادقة، الجلسات، التوجيه) | ✅ مختبر على Linux | اختبارات وحدة وتكامل ناجحة |

| محولات الوكلاء (Provider Adapters) | ✅ مختبر على Node.js | 6 اختبارات ناجحة |
| محلل البروتوكول (@@@ARENA_PC@@@) | ✅ مختبر على Node.js | 5 اختبارات ناجحة |

| قفل الموارد (Resource Locking) | ✅ مختبر على Linux | اختبارات قفل ناجحة |
